# OpenGL Campsite Environment

## Description
A simple 3D campsite environment created using C++ and OpenGL. The scene features a low-poly forest campsite with basic decorations and randomly placed trees.

## Features
- 3D grass ground and cliff environment
- Pine trees with randomized placements
- Camping tents
- Animated campfire
- Lanterns and rocks
- Entrance sign
- Free-look camera movement

## Technologies Used
- C++
- OpenGL
- GLEW
- FreeGLUT

## Project Structure
- `layout.cpp` – Contains the campsite environment, objects, and rendering functions.
- `main.cpp` – Main project source file.

## Author
Developed as part of a Computer Graphics and Visualization project.
